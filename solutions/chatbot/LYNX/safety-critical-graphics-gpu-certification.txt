Lynx Safety-Critical Graphics Ecosystem

Our solutions deliver reliable performance, simplify certification, and future-proof your edge computing systems.

Supported Graphics Processors & RTOS

Customer choice is our first priority. That’s why Lynx graphics enablement solutions can be used with a selection of supported graphics processors and real-time operating systems.

Operating System Abstraction Layer

The OS Abstraction Layer (OSAL) simplifies integration of Lynx’s GPU solutions with any RTOS, accelerating deployment of mission / safety critical applications while ensuring performance, interoperability, and certification.

Safety-Critical Graphics Certification

Meet stringent safety requirements with certification evidence for standards like DO-178C, ISO 26262, and IEC 61508.

GPU Supply & Obsolescence Management

Mitigate GPU supply chain risks with obsolescence management and COTS-D board designs that support domestic manufacturing.

Open Standard Graphics APIs

Our GPU enablement libraries are built using open standard graphics APIs managed by the Khronos Group. These APIs are supported directly in silicon by our semiconductor partners.

 Bringing AI into the Safety-Critical Graphics Ecosystem 

Building a safety-critical graphics ecosystem requires more than certified components. It requires a unified foundation where graphics, GPU compute, and AI workloads operate together with determinism and certification in mind. LYNX MOSA.ic.AI® brings this ecosystem together by unifying CPU and GPU software into a single, certifiable platform, enabling AI-driven graphics and compute workloads to execute predictably across the entire system lifecycle.

 Graphics Enablement for Safety-Critical Environments 

CoreSuite 2.0 is a suite of open-standard, Khronos-based graphics libraries with broad silicon support, enabling hardware-accelerated graphics, and video, along with profiling and monitoring tools to enhance reliability. Available CoreSuite 2.0 software components include: 

VkCoreSC®
: Certification-ready graphics libraries built on Vulkan SC API for safety-critical applications. 

TrueCore™
: GPU safety monitor providing real-time verification of graphics and compute pipelines to ensure reliability. 

ProfileCore
: Performance profiling tools to optimize application execution and validate Worst-Case Execution Time (WCET). 

EncodeCore®

/ DecodeCore®
: Video encoding and decoding tools with low latency, synchronized to the graphics pipeline. 

We also provide a 
COTS-D XMC Module,
 which is A DO-254 certification-ready GPU processor design that enables secure domestic manufacturing and simplified certification.
