WHAT WE'RE DOING TOGETHER

There have been two main threads around our partnership with LDRA:

Structural coverage analysis, also known as code coverage analysis, measures the extent to which software code has been exercised under specific test conditions. It generally refers to source code but can also reference object code verification. Several tier 1 customers creating complex mission-critical platforms need this code coverage analysis.
From its formation, Lynx has been a believer in open standards. LDRA is a verification authority that supports the Future Airborne Capability Environment (FACE). They act as an independent 3rd party to validate that Lynx’s LynxOS-178 software is truly conformant to this standard. This reduces vendor lock-in for OEMs as they can preserve their investment in software for reuse on new systems. It also drives innovation inside the ecosystem as companies must continue to evolve to win a customer’s business.
