VIRTUAL INTEGRATION ENVIRONMENT SOFTWARE
Easing the integration for a customer that is leveraging a virtual environment.

INTRODUCING VIE

In early July 2023, Lynx released a package of software for evaluation by customers and partners that:

Disaggregates 
LYNX MOSA.ic 
into a set of microservices

Provides support for virtual environments as a first-class citizen as compared with physical hardware

Enables customers to create software on servers for Linux and 
LynxOS-178 

Based on engagement and feedback with lead customers, Lynx advanced the capabilities of VIE and released it as an actual product.
